## What is this?

This repository is my journey through a **20-day coding mission** assigned by my mentor. The goal is simple but demanding — solve **5 problems every single day** for 20 consecutive days. No breaks, no skipping, no excuses.

**Total target: 100 problems in 20 days.**

---

## The Rules

- ✅ Solve **exactly 5 problems** every day
- ✅ Push all solutions to GitHub **before midnight**
- ✅ Each solution must include a **brief comment** explaining the approach
- ✅ No copying — understand before you write

## How to Run Solutions Locally

```bash

git clone https://github.com/suronjit02/20-daiys-problem-solving-mission.git

# Navigate to a specific day
cd 20-daiys-problem-solving-mission/Day-01

# Run any solution
node problem_1.js
```
